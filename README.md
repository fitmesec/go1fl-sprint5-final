# Модуль фитнес-трекера

Консольное приложение на Go для учёта дневной активности (ходьбы) и спортивных тренировок (бег, ходьба). Приложение парсит строки с данными, рассчитывает дистанцию, среднюю скорость и количество потраченных калорий, после чего выводит информацию в консоль.

## Структура проекта

Логика разделена на пять независимых пакетов в директории `internal`:

- **`spentenergy`** — расчёт дистанции, средней скорости и потраченных калорий при ходьбе и беге.
- **`personaldata`** — структура с персональными данными пользователя (имя, вес, рост) и метод для их вывода на экран.
- **`trainings`** — парсинг строк с данными о тренировках и формирование отчёта о них.
- **`daysteps`** — парсинг строк с данными о дневной активности (шагах) и формирование отчёта о них.
- **`actioninfo`** — общий интерфейс `DataParser` и функция `Info()`, объединяющая обработку тренировок и дневной активности.

## Запуск

Из корневой директории репозитория:

```bash
go run ./cmd/tracker
```

## Тестирование проекта

Рядом с редактируемыми файлами находятся файлы с суффиксом `_test.go`. В них содержатся юнит-тесты, проверяющие корректность реализации. Тесты автоматически запускаются на GitHub. Для зачёта работы код должен успешно проходить все тесты. Изменение содержимого тестов запрещено.

Запуск тестов локально выполняется из корневой директории репозитория:

```bash
go mod tidy
go test -v ./...
```
